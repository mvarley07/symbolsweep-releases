# symbolsweep-releases

[SymbolSweep](https://www.symbolsweep.com) is a macOS menu bar app that reclaims dev disk space. It keeps the runaway Xcode symbolication cache (`com.apple.coresymbolicationd`) in check and finds DerivedData, node_modules and other build caches, showing you exactly what's safe to delete.

This repository holds only compiled binaries and `latest.json` (the Tauri updater manifest). The application source code lives elsewhere.
